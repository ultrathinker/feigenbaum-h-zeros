## Вердикт

> **ЗАКРЫТО СТРОГО.** Для каждого из 25 дисков (23 кольцевых теоремы 2 + 2 диска
> теоремы 1) знаменатель x_{2^m} функционала базы, вычисленный на **предельном
> срезе** slice_∞(u), не имеет нулей внутри диска. Оговорка комплекта
> «обмотка знаменателя вычислена численно, а не интервальным сертификатом»
> (§5.3(v), §8 п.5) снимается: цепочка теперь полностью сертифицирована.

Состав цепочки — три сертифицированных компонента и одна элементарная лемма:

## 1. Мостовая лемма (математика; нового счёта не требует)

Обозначим D(u; f) = x_{2^m}(f) — знаменатель орбиты функции f на уровне m,
base(u) — базовый срез (центр трубки), slice_∞(u) — предельный срез, Γ — контур диска.

**Дано:**
- **(a)** D(u; f) ≠ 0 для всех u ∈ Γ и **всех** f из трубочного шара
  B(base(u), r_s), r_s = 5.44×10⁻⁷ — это сертифицированный факт
  `x128_lower > 0` на всех 1465 рабочих трубочных дугах пяти групп
  (h1pkg_certificate.json, худшее значение 1.1186×10⁻³);
- **(b)** ‖slice_∞(u) − base(u)‖₁ ≤ P_tail = 4.5693×10⁻⁷ < r_s равномерно по u
  (h1pkg tail_resolution, primary-вариант M3=1834 с обоснованной применимостью);
- **(c)** wind(D(·; base), Γ) = 0 — строгая интервальная обмотка
  (winding-пакет волны v3 + новые прогоны этого пакета);
- **(d)** D(u; slice_∞(u)) голоморфен по u внутри диска (индукция с принципом
  максимума — §5.3(v) статьи; орбита не содержит делений).

**Утверждение:** D(u; slice_∞(u)) ≠ 0 внутри диска.

**Доказательство.** Шар B(base(u), r_s) выпукл, поэтому
f_λ(u) = base(u) + λ·(slice_∞(u) − base(u)) лежит в нём при всех λ ∈ [0,1] (по (b)).
Гомотопия (λ, t) ↦ D(u(t); f_λ(u(t))) непрерывна и не обращается в 0 на Γ (по (a)),
значит wind(D(·; f_λ), Γ) не зависит от λ. При λ=0 она равна 0 (по (c)),
следовательно wind(D(·; slice_∞), Γ) = 0. По принципу аргумента для голоморфной
внутри диска функции (d) число нулей внутри равно обмотке, то есть нулю. ∎

## 2. Машинная часть (bridge_certificate.py, все входы под sha256)

1. **Компонент (c) — обмотки базового среза.** Существующий пакет
   `article_v1/v3_work/winding/` (13.08, verify PASS, порчи 8/8 + 6/7) даёт
   wind = 0 на 25 дисках. Обнаруженный пробел уровней закрыт **новым счётом**
   той же аудированной машиной (световые аффинные формы, Arb 512 бит):
   - **Z57, m=8** (орбита 256): wind = 0 ± 9.0×10⁻²⁵, min|x_256| ≥ 3.077×10⁻³;
   - **Z60, m=8**: wind = 0 ± 9.1×10⁻²⁵, min|x_256| ≥ 2.976×10⁻³;
   - **Z72, m=7** на сдвинутом контуре (опционально, для полноты обоих
     уровней): wind = 0 ± 1.8×10⁻²⁵, min|x_128| ≥ 5.916×10⁻³.
   Теперь у Z57/Z60 обмотка сертифицирована на **обоих** уровнях 7 и 8
   (закрытие соответствует point14_m8_base, который держит трубочные дуги
   обоих уровней), у Z72 — тоже на обоих (7 новый, 8 из winding-пакета).
2. **Компонент (a) — скан 1542 трубочных файлов** пяти групп: 1465 рабочих дуг,
   77 NEG-контролей, `x128_lower > 0` на каждой рабочей дуге, худшее
   1.118605×10⁻³ (D_MINUS) —**побайтово совпало со сборочным сертификатом
   h1pkg** (число, файл, счётчики).
3. **Компонент (b) — вложенность:** P_tail = 4.5693×10⁻⁷ < min r_s по всем
   дугам = 5.44×10⁻⁷, запас 0.87×10⁻⁷ (пере-читано из h1pkg под пином).
4. **Таблица моста по дискам:** каждой паре (диск, уровень) сопоставлены
   обмотка и трубочные дуги; требуемые уровни: 7 для 20 census-дисков и
   D_MINUS/D_PLUS; {7, 8} для Z57/Z60; 8 для Z72. Все требуемые пары закрыты
   (`all_disks_bridged = true`).

## 4. Что этот пакет НЕ делает (границы)

- Не пере-верифицирует внутренности трубочных дуг (домен, хвосты) — это ядро
  принятого H1-пакета (cert_D + независимый верификатор E + батарея F).
- Не пере-верифицирует winding-пакет по 22 дискам уровня 7 — у него свой
  верификатор и две батареи порч; здесь его результаты читаются под sha256.
- Индукция голоморфности внутри диска (пункт (d)) — прозаическая математика
  §5.3(v) статьи, машиной не проверяется (и не проверялась нигде).
- Применимость M3 = 1834 (через Amax = 1.35×10⁻⁴ < 2×10⁻⁴) — принята из
  h1pkg m3_resolution, как и во всей статье.
- Для строк уровня 8 (Z57/Z60/Z72) вложенность предельного среза в трубку
  опирается на принятую конструкцию статьи «якорь хвостовой мажоранты на
  уровне 7» (point14/point17): P_tail на базе 8 мажорируется цепочкой,
  заякоренной на уровне 7, и не превосходит использованного здесь
  P_tail(m₀=7) = 4.5693×10⁻⁷ — хвост с более глубокой базы короче. Отдельного
  пере-вывода этой мажоранты пакет не делает.

## 4b. Ревизия Fable (REVISE) и внесённые правки — 14.08, вторая половина дня

Пакет прошёл независимое ревью (Fable, отчёт `review_fable/REVIEW_FABLE.md`).
Вердикт **REVISE**: математика моста и все числа подтверждены третьим кодовым
путём (64 точки × 4 контура), но найден дефект бухгалтерии. Все находки
внесены; после правок сертификат перегенерирован и переверифицирован (PASS).

1. **[исправлено] Инвертированная обязательность (Z72, L7).** Несущий уровень
   голоморфности — 7 для **всех** 25 дисков (F_{m₀}, m₀=7; работа m=8 —
   про перенос обмотки H_m, не про голоморфность). Пакет ставил
   `required_levels["Z72"]={8}`, а строке L7 приписывал 128 дуг
   `Z72_stage9_L7`, которые дробят лишь 16 из 64 дуг контура (индексы
   48–199 с дырами). Полное покрытие L7 — семья `Z72_shifted` (64/64 дуг,
   смежные индексы, маркер уровня H7_abs_lower, проверено пофайлово) —
   ранее выбрасывалась как немаркированная. Исправлено: `Z72_shifted` →
   (Z72, 7), `Z72_shifted_L8` → (Z72, 8), stage9-семьи — в отдельную
   неблокирующую корзину refinement; required_levels = {7} для всех,
   {7,8} для Z57/Z60/Z72.
2. **[исправлено] Проверка замощения контура.** Введена пофайловая сборка
   семей с требованием смежности индексов 0..K−1; покрытие пары

   семьи. Добавлен пофайловый контроль маркера уровня (H7/H8_abs_lower).
3. **[исправлено] Дыры верификатора на отчётных полях.** Добавлены пересчёты:
   containment_margin, пофамильная сверка (имя/группа/число дуг/смежность/
   минимум), refinement-корзина; допуски min_abs/max_w ужаты 2×10⁻² → 10⁻³.
   В батарею добавлены 4 порчи, включая обе пропущенные ревизией и симуляцию
   самого бага атрибуции (T10).
4. **[исправлено в комплекте] Округление нижних границ**: §5.3(v) статьи —
   1.12→1.11×10⁻³ и 2.4→2.3×10⁻³ (нижние границы округляются вниз).
5. **[зафиксировано] Провенанс P_tail.** В обороте два верхних предела одной
