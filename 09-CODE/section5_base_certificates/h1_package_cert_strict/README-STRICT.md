# h1_package_cert_strict — строгие сертификаты леммы W и радиуса r_s (подмножество release_h1/CERT)

Источник в архиве: `article_v1/v3_work/release_h1/CERT/` (папка релиза H1, собранная после
h1pkg-сертификата; см. README-CODE.md §2). Здесь — только та её часть, которая нужна для
воспроизведения печатных чисел §5.4–5.5 и прил. B §2–3 статьи, вместе с её входами:

| Файл | Что делает |
|---|---|
| `CERT/level_tail_certificate_strict.py` → `.json` | лемма W (парный инвариант) со **строгими** ‖DT(G)‖₁ = 22.191604188675928, ‖DT(G)²‖₁ = 193.634437825475… (из `DATA/inputs/.../ndt_rigorous.json`; независимый дубликат `archive_inputs/w36/proj_codex/rigorous_block.json`); даёт 261.0804 ≤ 1000, **1279.3512 ≤ 1280**, **936.8487 ≤ 1000**, P_all ≤ 2.1134×10⁻⁷, P_tail ≤ 4.569368×10⁻⁷ < 5.44×10⁻⁷ |
| `CERT/radius_K284_certificate.py` → `.json` | радиус трубки r_s ≤ 3.5661×10⁻⁷ |
| `CERT/_constants.py` | все входные константы с провенансом (δ_lo/δ_hi, K = 284, ‖h‖₁, …) |
| `_log.py` | журнал прогресса (`progress.log`) |

Замороженный `archive_inputs/w36/audit_codex/level_tail_certificate.py` использует литералы
22.19 / 193.63 (округлены ВНИЗ и потому формально не верхние границы) и даёт 1279.2777 / 936.8200;
печатные в статье 1279.3512 / 936.8487 — из строгой версии в этой папке.

Запуск (из этой папки, python-flint): `python CERT/level_tail_certificate_strict.py`,
`python CERT/radius_K284_certificate.py` — оба перезаписывают свой `.json`; при сборке
пакета оба JSON пересозданы и побайтно (по содержимому) совпали с архивными.
