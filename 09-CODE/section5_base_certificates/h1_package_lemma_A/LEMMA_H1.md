## 0. Постановка и обозначения

Пусть `A = ℓ¹(ℕ₀, ℂ)` с нормой `‖f‖₁ = Σ|fₙ|` и свёрточным умножением. `G`
— сертифицированная неподвижная точка оператора ренормализации Фейгенбаума
(`cl34_certificate.json`: `‖G−g₀‖₁ ≤ 4.67e-61`). Оператор `T` определён
формулой `T(f) = f(v(f))/a`, `a = f(0)`, `u(f) = (a²−1)/R + a²w`,
`v(f) = (f(u(f))²−1)/R`, `R = 5/2`, `w = (X−1)/R`
(`A1_ANALYTICITY_PROOF.md:42-59`; свёрка нормировки — `IDENTITY_B.md` §B*).

Для `m₀ = 7` и параметра `u` положим `s_k(u) = u·AU₀/δ^k`, `AU₀ =
0.414037999086273` (`x4_common.py:AU0`), `δ = 4.66920160910299`
(`w33_gh_hiprec.json:delta_rayleigh`). Орбита: `x₀ = 0`,
`x_{n+1}(u) = g(w_n) + s_k(u)·h(w_n)`, `w_n = (x_n²−1)/2.5`. Функция уровня:
`H_k(u) = x_{2^{k+1}}(u)/x_{2^k}(u)`.

**H1 (цель):** предельная `H(u) = lim_{k→∞} H_k(u)` голоморфна в окрестности
каждого из 25 замкнутых дисков `D̄`.

Ключевой объект — **срез**: `slice_k(u) := T^{k−m₀} f_{s_k(u)}`, где
`f_s = G + s·h`, и **функционал базы**: `F_{m₀}(x) := (T^{m₀}x)(1)`.

**Тождество ренормализации** (доказательство с явным членом ошибки —
`IDENTITY_B.md`):

    (Tf)^n(0) = f^{2n}(0)/a,   x_{2n}(f) = a·x_n(Tf),
    H_k(u) = H_{m₀}(T^{k−m₀} f_{s_k(u)}) = F_{m₀}(slice_k(u)).   (∗)

Член ошибки тождества: `|s_{m₀}|·|h(−0.4)| ≤ 9.9e-5·1.63e-29 = 1.6e-33` —
ничтожен (см. `IDENTITY_B.md` §B).

## 1. Лемма (а0) — срезы образуют равномерно сходящуюся последовательность Коши

> **Лемма (а0).** Для каждого диска `D̄` последовательность
> `{slice_k(u)}_{k≥m₀}` является равномерно по `u ∈ D̄` последовательностью
> Коши в `ℓ¹`. Именно, для `j > k ≥ m₀`:
>
>     sup_{u∈D̄} ‖slice_j(u) − slice_k(u)‖₁  ≤  P_tail(k),
>
> где `P_tail(k) → 0` геометрически при `k → ∞`. Несущая скорость —
> `√q = √0.427 = 0.654` за уровень (DE-матрица, `level_tail_certificate.json:23`);
> более быстрые компоненты — Дюамель `ratioP = 0.016` и неустойчивая
> `1/δ = 0.214`. Все три `< 1`. При этом полный хвост из трёх слагаемых
> `P_tail(m₀) = P_all + ‖P_perp‖₁·D_star + ‖h‖₁·e_star/(1−1/δ) ≈ 4.57·10⁻⁷`
> (при `e_star = 1.245·10⁻⁸` из `level_tail_certificate.json:27`, M3=1834;
> консервативная оценка с M3=123479 даёт `4.78·10⁻⁷`) `< tube_radius = 5.44·10⁻⁷`.
> Архивный `r_s = 3.566·10⁻⁷` (`radius_K284_certificate.py:14`) — **неполный
> учёт**: он равен лишь первым двум слагаемым и опускает l-компонентный хвост
> `‖h‖₁·e_star/(1−1/δ)`; рабочей величиной пакета является `P_tail(m₀)`.
>
> Следовательно ряд `Σ_{k≥m₀}(slice_{k+1} − slice_k)` сходится абсолютно и
> равномерно, и `slice_k → slice_∞` в `C(D̄, ℓ¹)`.

*(Третий проверяющий (`REVIEW_PLAN_DS.md:58-86`) справедливо указал, что
сходимость срезов нигде не была выведена, а подавалась как готовое число. Ниже
— вывод. Несущее утверждение — свойство Коши, а не точное равенство суммы
приращений `P_all` (см. замечание в конце доказательства).)*

**Доказательство.** Шаг 1 (разложение Дюамеля). По лемме W
(`level_tail_certificate.py:26-34`, проверено: коэффициенты `261 ≤ 1000`,
`1279 ≤ 1280`, `937 ≤ 1000`, `pass=true`), поперечное отклонение `w` на
границе пары удовлетворяет `w ≤ C₀·s²`, `C₀ = 1000`, а на промежуточном шаге
`w ≤ C₁·s²`, `C₁ = 1280`. Отсюда (`:36`) `Q_j ≤ QCOEF·s_j²` равномерно по
всем уровням-источникам `k`.

Шаг 2 (структура вкладов). Дюамелева сумма для отклонения среза `slice_k` от
ренормализационной прямой `G + s_{m₀}(u)·h` есть сумма послойных вкладов
(`duhamel_ds/w36_duhamel.md:114`):

    P w_exit(k) = Σ_{i=0}^{n−1} DT(G)^{n−1−i} P_perp Q_i,   n = k−m₀.

Вклад уровня `j = m₀+1+r` (где `r = j−m₀−1` — «обратное расстояние»),
распространённый до базы, ограничен по норме величиной

    ‖вклад_j‖₁ ≤ QCOEF · s_j² · ‖DT(G)^r P_perp‖₁.

При `r = 0`: `‖P_perp‖₁ = pperp = 2.808542` (`level_tail_certificate.py:19`,
`proj_codex`). При `r ≥ 1`: `‖DT(G)^r P_perp‖₁ ≤ Cs·μ^r`, `Cs =
5.495835`, `μ = 0.35` (`:19`, `proj_codex`). Поскольку `s_j² = (t/δ^j)²` и
`s_{m₀+1} = s₈ = t/δ⁸`, имеем `s_j² = s₈²·δ^{−2r}`. Поэтому

    ‖вклад_j‖₁ ≤ QCOEF · s₈² · Cs · μ^r · δ^{−2r}
               = QCOEF · s₈² · Cs · (μ/δ²)^r
               = QCOEF · s₈² · Cs · ratioP^r,

где `ratioP = μ/δ² = 0.016054` (`level_tail_certificate.py:40`,
`level_tail_certificate.json:13`). Для `r = 0` аналогично `‖вклад_{m₀+1}‖₁
≤ QCOEF·s₈²·pperp`.

Шаг 3 (ключевое: оценки вкладов не зависят от источника `k`). Граница
`‖вклад_j‖₁ ≤ QCOEF·s₈²·ratioP^r` зависит только от `j` (через `s_j =
u·AU₀/δ^j`) и `u` — но **не** от глубины источника `k`, поскольку `Q_j ≤
QCOEF·s_j²` есть равномерная по `k` оценка (лемма W, шаг 1). Добавление более
глубокого уровня добавляет к накопленному отклонению **один новый член** с
убывающей границей.

Шаг 4 (хвост → 0). h-компонента `slice_k` равна `s_{m₀}(u)·h` для всех `k`
(усиление `δ^{k−m₀}` в h-направлении в точности гасится убыванием `s_k =
u·AU₀/δ^k`, см. `IDENTITY_B.md` §B). Поэтому разность `slice_j − slice_k`
(j > k) лежит в поперечной части и мажорируется хвостом Дюамелевой суммы
(вклады от уровней `k+1, …, j`):

    ‖slice_j − slice_k‖₁  ≤  Σ_{ℓ=k+1}^{j} ‖вклад_ℓ‖₁
                         ≤  QCOEF·s₈² · Cs · Σ_{r=k−m₀}^{∞} ratioP^r
                         =  QCOEF·s₈² · Cs · ratioP^{k−m₀} / (1 − ratioP)
                         =:  P_tail(k)  →  0  при k → ∞,

поскольку `ratioP = 0.016 < 1`. В частности `P_tail(m₀) ≤ QCOEF·s₈²·kernel_sum
= P_all`. Для `k = m₀` это даёт суммарное накопленное отклонение от прямой.

Шаг 5 (сходимость). `P_tail(k) → 0` геометрически ⇒ `{slice_k}` равномерно по
`u ∈ D̄` последовательность Коши ⇒ `slice_k → slice_∞` в `C(D̄, ℓ¹)`. Ряд
`Σ_{k≥m₀}(slice_{k+1} − slice_k)` сходится абсолютно и равномерно, т.к. его
хвост мажорируется `P_tail(k)`. Равномерность по `u` следует из того, что все
оценки зависят от `u` только через `t = |u|·AU₀ ≤ 4.7911` (см. §4 ниже). ∎

**Шаг 4 в нелинейном случае — уравнение в вариациях** (вывод вместо
заявления; треугольник даёт лишь `2·P_all`, что к нулю не стремится).

Разложим `slice_ℓ = G + s_{m₀}(u)·h + p_ℓ`, `p_ℓ ∈ {l=0}` (поперечная
поправка; h-компонента `s_{m₀}(u)·h` постоянна по `ℓ` и сокращается в
приращении). Возмущение уровня `ℓ+1` есть `s_{ℓ+1} = s_ℓ/δ`, поэтому
поправка `q_ℓ` (порождаемая при `ℓ−m₀` шагах ренормализации) удовлетворяет
`‖q_ℓ‖₁ ≤ ‖p_ℓ‖₁/δ²` (лемма W, `Q_j ≤ QCOEF·s_j²`, возмущение в `δ` раз
меньше). Поскольку `DT(G)` сохраняет `{l=0}` (`l∘DT(G) = δ·l` ⇒
`l(DT(G)p)=0` для `p∈ker l`, `proj_codex`), рекурренция

    p_{ℓ+1} = DT(G)[q_ℓ] + R_ℓ ,   ‖R_ℓ‖₁ ≤ K·s_{m₀}² ,

даёт `‖p_{ℓ+1}‖₁ ≤ (Cs·μ/δ²)·‖p_ℓ‖₁ + K·s_{m₀}² = 0.0882·‖p_ℓ‖₁ + K·10⁻⁸`.
По принципу сжимающих отображений `p_ℓ → p_∞` геометрически, и приращения
убывают со скоростью `0.0882` (норма) или `ratioP = 0.016` (спектр). Нелинейный
остаток `R_ℓ` порождает h-направленный снос (l-компонента `e`), убывающий со
скоростью `1/δ = 0.214` (DE-матрица, `p = 1/δ²`). DE-матрица даёт
консервативную скорость `√q = 0.654`. Все три `< 1`. (Подробности —
`ADDENDUM_A0.md`.)

**Замечание о расхождении `duhamel_ds.log`.** В той же папке лежит
`duhamel_ds.log`, дающий `‖P w_exit‖₁ = 3.44–6.69·10⁻⁷` (FAIL vs `3e-7`).
Причина: `duhamel_audit.py:56` использует `M3 = 123479` (консервативная
оценка Коши `K/(r₀−r₁) = 284/0.0023`), тогда как `level_tail_certificate.py:13`
использует `M3 = 1834` — сертифицированное прямое значение
`m3_global_certificate.json` (`M3_global_upper = 1833.67`, радиус `2e-4`,
орбита в `B(G, Amax)`, `Amax ≤ 1.34e-4 < 2e-4`, `pass=true`). Значение
`1834` корректно применимо, поскольку фактическое отклонение орбиты `Amax ≤
1.34e-4` строго меньше радиуса сертификации `2e-4`. Число `P_all = 2.11e-7`
отвечает именно `M3 = 1834`; `duhamel_ds.log` — устаревшая консервативная
версия, требующая отсылки, а не игнорирования
(см. `REVIEW_PLAN_DS.md:88-112`).

## 2. Лемма (а1) — принцип максимума для трубочного случая

> **Лемма (а1).** Если доменная проверка `|w_n| < 1` сертифицирована на
> контуре `Γ = ∂D̄` для всех `n = 0,…,2^{m₀+1}−1` и для всех возмущений
> трубки `v ∈ B_s(r_s)` (шар радиуса `r_s = 5.44e-7`), то `|w_n(u)| < 1` на
> всей внутренности `D̄` для тех же `n` и `v`.

**Доказательство.** Зафиксируем возмущение `v`. Функция `u ↦ w_n(u, v) =
((x_n(u,v))²−1)/2.5` голоморфна по `u` на внутренности `D̄` для каждого `n`:
индукция по `n`, `x₀ = 0`, `x_{n+1} = g(w_n) + s·h(w_n)` — композиция
голоморфных отображений (многочлены `g, h` степени 99 голоморфны всюду;
`PROOF_H1.md:98-111`, дыра №2). По принципу максимума для голоморфной
функции:

    max_{D̄} |w_n(·, v)| = max_Γ |w_n(·, v)|.

Доменная проверка сертифицирует `max_Γ |w_n(·, v)| < 1` (через аффинные
формы по дугам контура, `cert_slice_param_audit.py:353-355`, жёсткая проверка
`if not (rz < 1): raise`). Следовательно `max_{D̄} |w_n(·, v)| < 1`. Поскольку
это верно для каждого `v` из трубки, равномерно по `v`, внутренность покрыта.

**Почему трубочный случай не ломает голоморфность по `u`.** Зависимость от
возмущения `v` идёт через коэффициенты карты `g + v_0, h + v_1` (где
`(v_0, v_1)` — разложение `v` по `g`- и `h`-направлениям). Для каждого
фиксированного `v` функция `u ↦ x_n(u, v)` — одна голоморфная функция от `u`
(аффинная зависимость `s_k(u) = u·AU₀/δ^k` линейна по `u`). Трубка нужна
только для **оболочки** — для сертификации верхней оценки `|w_n|` сразу по
всем `v`, — а не для голоморфности по `u`. ∎

## 3. Лемма (R2) — домен ⇒ голоморфность F_{m₀} на трубке

> **Лемма (R2).** Функционал базы `F_{m₀}(x) = (T^{m₀}x)(1) = H_{m₀}(x)`
> фреше-голоморфен на трубке `B_s(r_s) ∩ {l = 0}` (множестве входов `x`, чья
> орбита остаётся в `|w| < 1`, а `x_{2^{m₀}}` отделено от нуля).

**Доказательство** (индукция по шагам орбиты; `PROOF_H1.md` звено A1, дыра №2;
`REVIEW_PLAN_DS.md:137-153`).

Орбита входа `x`: `y₀ = 0`, `y_{n+1} = g(w_n) + s·h(w_n)` (где `s` —
параметр карты `x`), `w_n = (y_n²−1)/2.5`. Тогда `F_{m₀}(x) = y_{2^{m₀+1}}/
y_{2^{m₀}}`.

*База.* `y₀ = 0` не зависит от `x`. `y₁ = g(w₀) + s·h(w₀)`, `w₀ = −0.4` —
полином от `x` (через `s` и коэффициенты `x`), голоморфно.

*Шаг.* Если `y_n` голоморфна по `x` и `|w_n| < 1`, то `w_{n+1} = (y_{n+1}²−1)
/2.5` голоморфна, и `y_{n+2} = g(w_{n+1}) + s·h(w_{n+1})` — композиция
голоморфных (многочлены `g, h`; оценка композиции `f(q)` при `‖q‖₁ < 1` —
`A1_ANALYTICITY_PROOF.md:64-89`). Условие `|w_n| < 1` обеспечено леммой (а1)
для всех `x` трубки.

*Деление.* `F_{m₀}(x) = y_{256}/y_{128}`. Знаменатель `y_{128} = x_{2^{m₀}}`
отделён от нуля: сертифицированная нижняя граница `x128_lower > 0` на всех
проверяемых дугах всех 25 дисков (скан 1465 рабочих дуг 5 групп; всего файлов
1542, из них 77 NEG-контролей), худший запас `x128_lower ≈ 1.12·10⁻³` у диска
D_MINUS группы point3B (`cert_slice_D_MINUS_outerbox_tube_K100_P748a23.json`;
ранее ошибочно указывалось `5.6·10⁻³` у Z72 — то была локальная величина
census/`NEG_B2`, не глобальный минимум; `REVIEW_PLAN_DS.md:147`),
`cert_slice_param_audit.py:430-432` — жёсткая проверка `if not (den_lo > 0):
raise`). Значит `1/y_{128}` голоморфна, и `F_{m₀}` — голоморфна. ∎

## 4. Три обязательных абзаца

### (I) Равномерность по u

Все операторные оценки зависят от `u` только через скаляр `t = |u|·AU₀`
(`level_tail_certificate.py:12`, `t = 4.7911`; `duhamel_audit.py:66-68`,
`tmax = AU₀·(u_D + R_ARC) = 0.4140·11.5715 = 4.7911`). Отсюда `|u| ≤ t/AU₀
= 11.571`. Поскольку `|u|` — выпуклая функция (норма), её максимум на
замкнутом диске достигается на границе: `max_{D̄}|u| = |u_c| + ρ = max_Γ|u|`
(неравенство треугольника). Худший из 25 дисков — Z74, `|u_c| + ρ ≈ 9.99 <
11.571` (`interior_probe.log`, `REVIEW_PLAN_DS.md:125`). Поэтому оценка
`P_all` (и все производные) равномерна по всему диску, а не только по контуру;
внутренность покрыта автоматически.

### (II) Неверный потолок 4.907

Оценка `|H_k(u)| ≤ ‖G‖₁ + 6.27e-4 ≈ 4.907` из `PLAN_V2_KILO.md` пункт 1б
**неверна**, и третье проверяющее справедливо её отметило
(`REVIEW_PLAN_DS.md:194`). Причина: подмена башни. Оценка `‖T^{k−m₀} f_{s_k}
− G‖₁ ≤ 6.27e-4` верна для **частичной** башни `T^{k−m₀}` (от уровня `k` к
базе `m₀`, цепочка вверх). Но `H_k(u) = (T^k f_{s_k})(1)` (`IDENTITY_B.md`
(∗)) — **полная** башня `T^k` до нулевого уровня. h-компонента полной башни
усиливается до `s_k·δ^k = u·AU₀`, давая `‖T^k f_{s_k} − G‖₁` порядка
`|u|·AU₀·‖h‖₁ = 4.7911·6.3312 ≈ 30` (на худшем диске; мой пересчёт) —
радикально больше `6.27e-4`. Приложение A статьи даёт сертифицированные
нижние границы `|H_{m₀}|` на Γ: `21.98` (Z73), `21.50` (Z05), `17.72` (Z71),
`9.28` (Z72) — все `≫ 4.907`, что подтверждает ошибку. Правильная оценка
ограниченности (для Витали—Портер, см. ниже): `|H_k(u)| ≤ √2/x128_lower
≈ 1180` (из ограниченности орбиты `|w_n| < 0.40` и отделённости знаменателя) —
конечна, но груба. **Срезовый Вейерштрасс этой оценки не требует** (ему нужна
только лемма (а0), а не ограниченность `|H_k|`).

### (III) Запасной маршрут (Витали—Портер)

Если срезовый Вейерштрасс по какой-то причине не пройдёт (например, если
лемма (а0) не удастся провести в нелинейном случае), доступен откат на
Витали—Портер: (i) ограниченность `{H_k}` на `D̄` — `|H_k(u)| ≤ √2/x128_lower
≈ 1180` (конечна, из орбитальной оценки + отделённости знаменателя, §II);
(ii) поточечная сходимость — из сходимости срезов (лемма (а0), последовательность
Коши) и непрерывности `F_{m₀}` (лемма R2). Витали—Портер даёт локально
равномерную сходимость и голоморфность предела. Верхняя граница `|H_k|` на Γ
в настоящее время машиной не выдаётся (трубочные JSON содержат только
`H7_abs_lower`); её добавление — одна строка в `result` ядра
(`cert_slice_param_audit.py:474-486`, поле `H_abs_upper = ub(af_abs_upper(H))`),
но это отдельная работа, не готовый факт. **В данном тексте этот маршрут не
используется** — срезовый Вейерштрасс проходит и сильнее (даёт равномерную, а
не только локально равномерную сходимость).

## 5. Основная теорема

> **Теорема (H1).** Предельная `H(u) = lim_{k→∞} H_k(u)` голоморфна в
> окрестности каждого из 25 замкнутых дисков `D̄`.

**Доказательство.**

**(i) Голоморфность срезов по u.** `u ↦ f_{s_k(u)} = G + s_k(u)·h` аффинна
(линейна по `u`). `T` фреше-голоморфна на `B(G, 0.0025)`
(`A1_ANALYTICITY_PROOF.md`, A1 CLOSED: три барьера `‖u‖₁ ≤ 0.499 < 1`,
`‖v‖₁ ≤ 0.709 < 1`, `|a| ≥ 0.397 > 0`, `a1_certificate.json`,
отрицательные контроли `0.01 PASS`, `0.05–0.40 FAIL`). Цепочка
`T^j f_{s_k(u)}` для `j = 0,…,k−m₀` остаётся в `B(G, 6.27e-4) ⊂ B(G,
0.0025)`: h-компонента усиливается до `s_{m₀}(u)·‖h‖₁ ≤
4.7911/δ⁷·6.3312 = 6.27e-4` (`VERDICT_MAXPRINCIPLE.md` §(а), мой пересчёт
`6.269e-4`; `REVIEW_PLAN_DS.md:45`), поперечная `≤ r_s = 3.566e-7`
(`radius_K284_certificate.json:7`, `pass=true`). Композиция голоморфных ⇒
`slice_k(u) = T^{k−m₀} f_{s_k(u)}` голоморфна по `u` на `D̄`.

**(ii) Сходимость срезов (лемма (а0)).** `{slice_k}` — равномерно по
`u ∈ D̄` последовательность Коши с геометрическим хвостом `P_tail(k) → 0`.
Несущая скорость `√q = 0.654 < 1` (DE-матрица); `P_tail(m₀) ≤ 4.57·10⁻⁷`
(при M3=1834; консервативно `4.78·10⁻⁷` при M3=123479) `< tube_radius =
5.44e-7` (лемма (а0), §1; вывод нелинейного шага 4 — уравнение в вариациях,
§1, `ADDENDUM_A0.md`). Архивный `r_s = 3.566e-7` — **неполный учёт** (без
третьего слагаемого `‖h‖₁·e_star/(1−1/δ)`); рабочая величина — `P_tail(m₀)`
(`tail_resolution` сертификата; пересчитано в `BRIEF_R`, см. `RECONCILE_R.md`).
По теореме Вейерштрасса для `ℓ¹`-значных голоморфных функций: `slice_k →
slice_∞` равномерно на `D̄`, и `slice_∞ : D̄ → ℓ¹` голоморфна по `u`.

**(iii) Голоморфность F_{m₀} (лемма R2).** `F_{m₀}` фреше-голоморфна на
трубке `B_s(r_s)` (лемма R2, §3). Срезы и их предел лежат в трубке:
`‖slice_k(u) − (G + s_{m₀}(u)·h)‖₁ ≤ P_tail(m₀) ≈ 4.57·10⁻⁷ ≤ tube_radius =
5.44e-7` (`radius_K284_certificate.json:7-9` даёт неполный `r_s = 3.566·10⁻⁷`
— без третьего слагаемого; полный хвост `P_tail(m₀)` пересчитан в `BRIEF_R`,
запас до `tube_radius ≈ 0.87·10⁻⁷`).

**(iv) Композиция.** `H(u) = lim_k H_k(u) = lim_k F_{m₀}(slice_k(u)) =
F_{m₀}(slice_∞(u))` (непрерывность `F_{m₀}` на трубке). Композиция
голоморфных `u ↦ slice_∞(u)` и `F_{m₀}` голоморфна. ∎
