ЧАСТИЧНО

# Норма спектрального проектора и строгий темп хвоста

Численно-линейно-алгебраический блок прошёл. При входных сертификатах,
перечисленных ниже, Arb-счёт при 512 битах даёт

    ||DT(G)^j P_perp||_1 <= 5.495835 * 0.35^j,
    F*_fixed <= 1.582568,
    F*_tube  <= 1.648872.

Вторая величина учитывает, что во внутренней трубке действует произведение
`DT(xi_j)`, а не степень одного `DT(G)`. Она меньше бинарного порога `1.8`.
Условные запасы Руше на двух тесных зубьях получаются D `1.7072x`, N
`1.6294x`; оба превышают требуемые `1.5x`.

Вердикт оставлен `ЧАСТИЧНО`, а не `ДОКАЗАНО`: этот файл сертифицирует новый
спектральный блок, но принимает из предыдущей цепочки оценки `L_7`,
`min|H_5|`, `Delta_5+Delta_6`, трубку и базовые шары для `G,h`. Их
бесконечномерная корректность здесь заново не доказана.

## 1. Midpoint-гейт

Матрица собрана из 100 коэффициентов
`w33/t5_cert_sonnet/w33_gh_hiprec.json` в тейлоровском базисе
`w=(X-1)/2.5`. Нормированный касательный срез имеет размерность 99:

    E_0 = {q: q(X=0)=q(w=-0.4)=0}.

Это существенно: в полном чётном пространстве остаётся собственное значение
`alpha^2=6.2645478312`; там `I-h*l` не является устойчивым проектором.

Midpoint, float64, ровно 16 равноотстоящих узлов на каждой окружности:

| r | max по 16 узлам, координатная l1 | безопасная ambient-оценка | r * max ambient |
|---:|---:|---:|---:|
| 0.35 | 10.230335410 | 14.322469573 | 5.012864351 |
| 0.50 | 5.557091059 | 7.779927482 | 3.889963741 |

Это только измеренные сеточные максимумы, не оценки супремума. Проверки
сборки:

    ||T(G_0)-G_0||_1 = 1.704162e-15,
    ||DT(G_0)h-delta*h||_1 = 1.419808e-14,
    max |lambda_stable| = 0.159628440383,
    ||l||_inf = 1.10485425032,  l(h)=1.

Midpoint-кандидаты после исправления алгебры брифа: `F*=1.574675` при
`r=0.35` и `F*=1.584193` при `r=0.50`. Поэтому маршрут прошёл первый гейт.

## 2. Проверка алгебры брифа

Обнаружены четыре места, которые нельзя пропускать.

1. Проектор устойчив только на срезе `E_0`, не на полном пространстве.
2. Из разложения

       A^n = delta^n P_u + A^n P_perp

   для произвольного входа возникает множитель `||P_u||`. Коэффициент `1`
   перед неустойчивой частью без дополнительного направленного тождества
   неверен.
3. Полное продолжение функционала с нормой `1.1049` не оптимально на
   `E_0`. К функционалу можно прибавить аннулятор среза
   `c*(1,w_0,w_0^2,...)`, `w_0=-0.4`. Фиксированный выбор
   `c=-1.39051` даёт строгую оценку двойственной нормы на срезе

       ||l|E_0||_* <= 0.285655750.

   Отсюда

       ||P_u||_1 <= 1.808542,
       ||P_perp||_1 <= 2.808542.

   Грубое число `7.995` из брифа корректно как треугольная оценка через
   неоптимальное продолжение, но теряет множитель `2.85`.
4. Для хвостового входа нужна коэффициентная `l1`-норма внутренней
   композиции. Её нельзя заменять максимумом модуля на окружности.
   Получено `||B||_1 <= 0.692979106`, тогда как число `0.488246` относится
   к другой норме. Исправленная величина всё ещё даёт достаточно малый
   хвост.

Для фиксированного оператора правильный сумматор квадратичной огибающей:

    F*_fixed
      <= 1 + ||P_u||/(delta-1) + C_s*mu/(delta^2-mu)
      <= 1.582568.

Первый член равен `1`, потому что член `n=0` переносится тождественным
оператором; разложение на два проектора в нём применять не надо.

## 3. Сертификат левой пары

На полном 100-модовом блоке решалась дополненная система

    A^T l - lambda*l = 0,
    l(h) - 1 = 0.

Интервальный обратный якобиан посчитан Arb-LU. В радиусный полином включены
`||DT(G)-DT(G_0)||_1 <= K*rho_G`, неопределённость `h` и шуровская поправка
хвоста. Получены

    ||Y||_inf <= 6.830376,
    ||Y F(l_0,lambda_0)||_inf <= 7.924828e-15,
    rho_l <= 1.588343e-14,
    p(rho_l) <= -7.941714e-15.

Следовательно, при входных шарах существует единственная нормированная
левая пара в указанном окне. Для фактической сертифицированной правой пары
`Ah=delta*h`, `l(h)=1` даёт `(lambda-delta)l(h)=0`, поэтому её собственное
значение совпадает с `delta`.

Итоговые нормы:

    ||l_head||_inf <= 1.104854250319780,
    ||l_tail||_inf <= 6.990710e-17,
    ||l|E_0||_* <= 0.285655749680253,
    ||h||_1 <= 6.331193600692640.

Радиус `rho_l` хуже целевого `1e-27`, потому что начальное приближение пары
было float64. Для требуемой верхней нормы это не мешает: запас до выбранного
округления `0.285656` больше радиуса сертификата на десять порядков.

## 4. Бесконечный хвост мод

Хвост не был объявлен малым по наблюдаемым столбцам. Использована явная
мажоранта композиции. При весе `sigma=1.38`:

    ||U||_1                <= 0.495777065,
    ||B||_1                <= 0.692979106,
    ||U||_(1,sigma)        <= 0.556435872,
    ||B||_(1,sigma)        <= 0.983797713,
    ||DT||_(1 -> 1,sigma)  <= 269.805145.

Отсюда для разбиения на моды `<100` и `>=100`:

    ||A Q_100||_1                         <= 2.954330e-16,
    ||Q_100 A P_100||_1, ambient          <= 2.774225e-12,
    ||Q_100 A P_100||_1, координаты E_0   <= 3.883915e-12.

В эти числа включена вариация `G` радиуса `rho_G=1e-20`. Таким образом,
конечный LU поднят на бесконечное пространство через шуровское дополнение;
произвольные числа `1e-30` и `1e-60` из старого пробного кода не
использовались.

## 5. Локализация устойчивого спектра и резольвента

Независимо от midpoint-собственных значений проверено

    ||A^2 P_perp||_1 <= 0.082182326 <= 0.1225 = 0.35^2,
    r_spectrum(A|E_s) <= 0.286674599.

Поэтому круг `|z|=0.35` действительно охватывает весь устойчивый спектр и
не охватывает `delta`.

Для каждой окружности взято 128 узлов. Между узлами применена резольвентная
тождественность с максимальной хордой `d`; условие `M*d<1` проверено
интервально.

| r | max узлов, coord l1 | d | M*d | sup на всей окружности, ambient l1 | C_s=r*sup |
|---:|---:|---:|---:|---:|---:|
| 0.35 | 10.230336 | 0.008590077 | 0.087879367 | 15.702386 | 5.495835 |
| 0.50 | 5.557092 | 0.012271539 | 0.068194056 | 8.349301 | 4.174651 |

Все числа в трёх последних столбцах округлены наружу. Контур `r=0.35`
лучше после умножения на скорость и даёт

    ||A^j P_perp||_1 <= 5.495835 * 0.35^j,   j>=0.

## 6. Переход от A^j к произведению производных в трубке

Одной оценки степеней `A=DT(G)` недостаточно: в доказательстве возникает
произведение `DT(xi_(n-1))*...*DT(xi_0)`. Использованы уже выведенные
границы трубки

    ||w_j||_1 + D_j <= 2.8001e-7,
    k-j >= 8 на каждом входе производной.

Для худшего зуба D это даёт

    ||xi_j-G||_1 <= 0.000134549,
    ||DT(xi_j)-DT(G)||_1 <= 0.030108.

Кроме того, из того же сертифицированного блока

    ||A P_perp||_1 <= 0.878719.

Если `u_j=||P_u v_j||_1`, `s_j=||P_perp v_j||_1`, то покомпонентно

    [u_(j+1)]   [4.723654  0.054452] [u_j]
    [s_(j+1)] <=[0.084560  0.963279] [s_j].

Начальный вектор мажорируется `(1.808542, 2.808542)`. После умножения
матрицы на `delta^(-2)` её суммы строк не превышают `0.219165` и
`0.048063`; геометрическая матричная сумма замыкается. Arb даёт

    F*_tube <= 1.648872.

Это число больше фикс-точечного `1.582568`, но всё ещё меньше порога `1.8`.
Идеальный `delta/(delta-1)=1.2725` здесь не выдаётся за доказанный
сумматор: ненулевая вариация производной и нормы проекторов оплачены явно.

## 7. Пересчёт пяти зубьев

Взяты входные числа полностью выведенной цепочки радиуса `0.1000` из
`w36/opus_bootstrap/p5_final.py`. В таблице `B_tail/minH7` — доля
доступного бюджета; для Руше достаточно, чтобы она была меньше единицы.
Столбец «запас» округлён вниз.

| зуб | B_tail, верх | minH7, вход | B_tail/minH7, верх | запас, x |
|:---:|---:|---:|---:|---:|
| A | 0.052261 | 0.358212 | 0.145894 | 6.8543 |
| B | 0.173743 | 1.304300 | 0.133208 | 7.5070 |
| C | 0.026722 | 0.081631 | 0.327345 | 3.0548 |
| D | 0.435336 | 0.743220 | 0.585743 | 1.7072 |
| N | 14.05209 | 22.89720 | 0.613704 | 1.6294 |

Сертифицированный рычаг относительно старого `F*=3.5111154` равен не
идеальным `2.759x`, а `2.129x`. Этого достаточно: худший условный запас
равен `1.6294x`.

## ПОСЫЛКИ, КОТОРЫЕ НЕ ДОКАЗАНЫ

1. Приняты как вход истинные бесконечномерные шары
   `||G-G_0||_1<=1e-20`, `||h-h_0||_1<=1e-27` и
   `||D^2T||<=223.77`. Их исходные скрипты содержат отдельно отмеченную
   эмпирическую экстраполяцию хвоста коэффициентов; этот файл не превращает
   её задним числом в доказательство.
2. Принята граница внутренней трубки `||w_j||+D_j<=2.8001e-7` из
   `w36/opus_bootstrap/p3_assemble.py`. Здесь проверено её использование,
   но не повторён весь сертификат `D^3T` и bootstrap.
3. Приняты входы цепочки `L_7`, Cauchy-границы, `min|H_5|` и
   `Delta_5+Delta_6` из `p5_final.py`. В частности, этот файл не доказывает
   независимо ко-векторное тождество для семи внешних шагов. Папка
   `w36/L7_work_ds` не читалась.
4. Приняты существование предельной `H` и корректность телескопического
   тождества из предшествующей цепочки проекта.

При этих посылках новый spectral-projector блок и пересчёт `F*` являются
интервальными. Без них глобальное утверждение о пяти нулях `H` этим файлом
не объявляется доказанным.

## САМОПРИЗНАННЫЕ СЛАБОСТИ

1. Радиус левой пары `1.588343e-14` ограничен float64-затравкой. Для нормы
   этого достаточно, но это не воспроизводит прежнюю точность правой пары.
2. Верхняя оценка хвоста `Q_100 A P_100` консервативна: вес `1.38` выбран
   вручную, близко к границе `||B||_(1,sigma)<1`. Это не влияет на итог,
   потому что шуровская поправка остаётся меньше `4e-12`.
3. Переход от координат среза к ambient-норме оплачен множителем `1.4`.
   Точная полиэдральная норма дала бы меньшее `C_s`, но не нужна для гейта.
4. Финальные запасы имеют лишь 4–6 надёжных цифр из-за округлённых входов
   `L_7`, Cauchy и `minH5`, хотя собственный Arb-блок посчитан при 512 битах.
5. Исходный код сборки `DT` не модульный. Конверсия импортирована из
   `w1_uncond_common_M99.py`, а дуальная композиция перенесена дословно в
   локальный скрипт и сверена с midpoint-реализацией.

- `rigorous_block.py`, `rigorous_block.log`, `rigorous_block.json` —
