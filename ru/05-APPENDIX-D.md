# Приложение D. Координатная мода (классический факт), явный вывод для нашей нормировки

**Самодостаточное приложение.** Все определения приведены внутри; читатель, знакомый с банаховым анализом и теорией ренормализации Цвитановича—Фейгенбаума, восстанавливает вывод целиком, не обращаясь ни к каким внешним материалам. Численные входы явно отделены от аналитических шагов (§6). Недостающая двойка выведена явно (§2, ядро приложения), а не постулирована.

> **Утверждение 5 (координатная мода; классический факт в явной форме для нашей нормировки).** Пусть `φ` — функционал вычисления в
> нуле в чётном представлении, нормированный условием `φ(G) = 1`. Тогда
> `φ ∘ DT(G) = c · φ`, причём `c = G′(1)/G(1) = α² = 6.264547831217…` в записи через
> производную по `x` (эквивалентно `c = 2G′_X(1)/G(1)` в записи через `X = x²`), и тот
> же множитель `c` есть собственное значение координатной моды
> `N = G − x·G′ = G − 2X·G′_X`: `DT(G) N = c · N`.
>
> **Внимание к записи.** Двойка принадлежит исключительно `X`-записи. Выражение
> `2G′(1)/G(1)` с производной по `x` равно `2α²`, а не `α²`; смешение двух записей —
> самая частая ошибка в этом месте, и §2 посвящён именно ей.

В этом приложении значок штриха `G′` без нижнего индекса означает **производную по вещественной переменной `x`** (`dG/dx`); запись `G′_X` означает производную по `X = x²` (`dG/dX`). Их связывает цепное правило — и именно здесь живёт двойка (§2).

---

## 1. Постановка и определения

**Пространство.** Работаем в банаховом пространстве чётных функций, заданных степенным рядом по `w = (X − 1)/2.5`, `X = x²`:

```
v(X) = Σ_{k≥0} v_k · w^k ,   w = (X − 1)/2.5 ,   ‖v‖₁ = Σ|v_k|.       (B = ℓ¹)
```

Чётность встроена в представление: `v(x) := v(X = x²)` автоматически удовлетворяет `v(−x) = v(x)`. Все нужные ниже точки (`x = 0` ⇒ `X = 0` ⇒ `w = −0.4`; `x = 1` ⇒ `X = 1` ⇒ `w = 0`) лежат внутри замкнутого единичного круга по `w` (`|w| ≤ 1`), поэтому ряды абсолютно сходятся и перестановка сумм при композиции и дифференцировании законна (сходимость установлена строгими методами и принята как вход настоящей работы — Ланфорд 1982, Кампанино—Эпстейн 1981).

**Функционал и срез.**

```
φ : B → ℝ ,   φ(v) := v(X = 0) = v(x = 0) = Σ_k (−0.4)^k v_k .
M := { q ∈ B : φ(q) = 1 }   (q(0) = 1 — стандартная нормировка Фейгенбаума),
E₀ := ker φ  (касательное пространство к M).
```

`φ` непрерывен: `|φ(v)| ≤ Σ 0.4^k |v_k| ≤ ‖v‖₁`.

**Оператор удвоения (самоприменённая форма).** Универсальная неподвижная точка `G` определяется самоприменённым оператором удвоения — та же форма, что используется в основном тексте для `δ` и `h`:

```
(T q)(X) := q( q(a² · X)² ) / a ,   a := q(X = 1) = значение q при w = 0.   (T)
```

`G` — его неподвижная точка: `(T G)(X) = G(X)`. Вещественная форма: `G(x) = −α · G(G(x/α))`, где `α` — вторая константа Фейгенбаума. Область определения `T` — `{q : q(1) ≠ 0}` (открыто); для `G` и его малой окрестности это выполнено.

**Константа α и её знак.** Сертифицированные данные пары (G, h) из §2.1 основного текста задают

```
α = +2.502907875095892822283902873218…      (положительное соглашение)
λ := G(1) = −0.39953528052313448985758046863369…
```

Самосогласованность (одно тождество, в точке `x = 0`): нормировка `G(0) = 1` и уравнение `G(x) = −α·G(G(x/α))` при `x = 0` дают `1 = −α·G(G(0)) = −α·G(1) = −α·λ`, то есть **`λ = G(1) = −1/α`**. Это АНАЛИТИЧЕСКОЕ следствие уравнения и нормировки; численно оно подтверждено до 159 значащих цифр — до полной точности данных (`|G(1) + 1/α|/(1/α) ≈ 1.1·10⁻¹⁵⁹`). Нам это понадобится в §2 и §4.

*(Для сведения: в разделе 1 основного текста `α` указано с обратным знаком; `α²` от знака не зависит. Ниже всюду `α > 0`.)*

## 2. ЯДРО ПРИЛОЖЕНИЯ: недостающая двойка

Здесь мы выводим то, что в кратких формулировках обычно просто утверждается. В `X`-записи собственное значение равно `c = 2G′_X(1)/G(1)` — с двойкой. Покажем, **откуда берётся эта двойка** и почему «наивное» дифференцирование даёт ровно половину.

### 2.1. Источник двойки: чётность и цепное правило

Функция `G` чётна по `x`, и её «естественная» переменная — не `x`, а `X = x²`. Запишем `G` как функцию от `X`: `G(x) = g(X)`, `X = x²`. Тогда производные по разным переменным связаны цепным правилом:

```
dG/dx  =  (dg/dX) · (dX/dx)  =  (dg/dX) · 2x .                       (цепное)
```

В точке `x = 1` (где `X = 1`):

```
G′(1) [по x]  =  2 · (dg/dX)|_{X=1}  =  2 · G′_X(1) .
```

**Вот и вся двойка:** она приходит из `d(x²)/dx = 2x`, оценённого в `x = 1`. Это в точности та «двойка из дифференцирования квадрата», о которой говорит формулировка теоремы: *«из-за чётности представления подстановка числа означает подстановку его квадрата, и недостающая двойка приходит из дифференцирования квадрата»*. Подставить число `x` в чётную функцию — значит подставить `x²` в функцию от `X`; продифференцировать по `x` — значит пройти цепное правило через `x²`, что и умножает на `2x`.

### 2.2. Почему «наивная» форма даёт половину

Если, вычисляя собственное значение, продифференцировать «по `X` напрямую», забыв о цепном правиле (то есть взять `(dg/dX)(1)/G(1)` вместо `(dG/dx)(1)/G(1)`), мы получим **ровно половину**:

```
c_наивн := G′_X(1)/G(1)  =  (1/2)·(dG/dx)(1)/G(1)  =  c/2  =  α²/2 .
```

Численно (независимый пересчёт в арифметике высокой разрядности по тем же сертифицированным данным; `G` представлен 100 чебышёвскими коэффициентами, преобразование Чебышёв → Тейлор в `w`-базисе выполнено заново):

```
G(1)            = −0.39953528052313448985758046863369…   (= −1/α)
(dg/dX)(1)      = −1.25145393754794641114195143660911…
(dG/dx)(1)      = −2.50290787509589282228390287321822…   = 2·(dg/dX)(1)
c := (dG/dx)(1)/G(1)  = 6.26454783121703742510990740759157…   = α²
c_наивн := (dg/dX)(1)/G(1) = 3.13227391560851871255495370379578… = α²/2
```

Таким образом, константа в `X`-записи пишется как `c = 2G′_X(1)/G(1)` (двойка явная), а в «сырой» `x`-записи — как `c = G′(1)/G(1)` (двойка спрятана в определении `G′` как производной по `x`). Это **одно и то же число**; путаница между записями и порождает эффект «наивная форма даёт половину». Никакого отдельного «поправочного множителя 2» к выводу не приклеивается — это просто правило цепочки для `X = x²`.

### 2.3. Сверка двух конвенций производной

| величина | запись | значение |
|---|---|---|
| производная по `x` (RAW) | `G′(1) = (dG/dx)(1) = 2G′_X(1)` | −2.5029078750958928… = −α |
| производная по `X` | `G′_X(1) = (dG/dX)(1)` | −1.2514539375479464… |
| константа, RAW | `c = G′(1)/G(1)` | 6.2645478312170374… = α² |
| константа, `X`-запись | `c = 2G′_X(1)/G(1)` | то же |

Заметим, что `G′(1) = −α` численно (132 значащие цифры совпадения с сертифицированным `α`). Это **не** аналитическое тождество — оно не выводится из функционального уравнения (см. §6), и его точность ограничена точностью аппроксимации `G` (усечение `M = 99`), а не округлением. Именно оно — единственное численное звено, превращающее аналитическую конструкцию §3–§5 в буквальное `c = α²`.

## 3. Производная Фреше `DT(G) v` (для произвольного `x`)

Пусть `v ∈ B`, `f_ε = G + ε·v`. По определению `(DT(G) v)(x) = d/dε[(T f_ε)(x)]|_{ε=0}`. Положим `a(ε) = f_ε(1) = λ + ε·β`, `β := v(1)`.

**Внутренняя композиция** `p(ε,x) = f_ε(a(ε)·x)`. Дифференцируя по `ε` (`a′(0) = β`):

```
∂p/∂ε|₀ = G′(λ x)·x·β  +  v(λ x).                                       (3a)
```

**Внешняя** `Num(ε,x) = f_ε(p(ε,x))`:

```
∂Num/∂ε|₀ = G′(G(λ x))·[ x·β·G′(λ x) + v(λ x) ]  +  v(G(λ x)).          (3b)
```

**Деление** на `a(ε)` (правило частного, `a(0) = λ`):

```
DT(G)v(x) = [ (∂Num/∂ε|₀)·λ − Num(0,x)·β ] / λ² .
```

Используем, что `G` — неподвижная точка: `G(G(λ x)) = λ·G(x)` (это `(T G) = G`, умноженное на `λ`). Тогда `−Num(0,x)·β/λ² = −G(x)·β/λ`. Далее, дифференцируя тождество `G(x) = G(G(λ x))/λ` по `x`, получаем ключевое упрощение `G′(x) = G′(G(λ x))·G′(λ x)` (множители `λ` сокращаются), так что `x·G′(G(λ x))·G′(λ x) = x·G′(x)`. Собирая:

```
DT(G) v (x) = (1/λ)·[ v(G(λ x)) + G′(G(λ x))·v(λ x) ]
              + (β/λ)·[ x·G′(x) − G(x) ].                                 (3c, RAW)
```

Подставляя `λ = −1/α` (т.е. `λ x = −x/α`, `1/λ = −α`) и обозначая `N(x) := G(x) − x·G′(x)` (координатный вектор, §5; заметим `x·G′(x) − G(x) = −N(x)`):

```
DT(G) v (x) = −α·[ v(G(−x/α)) + G′(G(−x/α))·v(−x/α) ]  +  α·v(1)·N(x).   (**)
```

**Первое слагаемое** — «главный член». **Второе** — поправка `+α·v(1)·N(x)`, пропорциональная `v(1)`. Она тождественно обнуляется лишь при `v(1) = 0`. В частности, ровно в точке `x = 0` оба слагаемых с `v(1)` сокращаются (см. §4), чем и объясняется, почему формулировки, работающие только с `φ` (вычисление в нуле), эту поправку не замечают. Вдали от нуля (при `v(1) ≠ 0`) без неё формула неверна.

## 4. Тождество `φ ∘ DT(G) = c·φ` (Лемма E₀)

**Шаг 1.** `T` отображает срез `M` в `M` точно, для любого `q ∈ M`: при `q(0) = 1`, `a = q(1)`, `(T q)(0) = q(q(0)²)/a = q(1)/a = a/a = 1`. Алгебраическое тождество, не приближение.

**Шаг 2.** Следовательно `E₀ = ker φ` инвариантно относительно `DT(q)` для любого `q ∈ M`: для `v ∈ E₀` кривая `q + ε·v` лежит в `M` при всех `ε`, её образ `(T(q + ε v))(0) = 1` постоянен по `ε`, и производная в нуле даёт `φ(DT(q) v) = 0`. В частности для `q = G`.

**Шаг 3.** `DT(G)` переводит `ker φ` в `ker φ`, значит функционал `φ ∘ DT(G)` обращается в нуль на `ker φ`. Линейная алгебра: функционал, зануляющийся на ядре ненулевого функционала `φ`, ему кратен:

```
φ ∘ DT(G) = c · φ    для некоторого скаляра c.                            (Лемма E₀)
```

**Значение `c`.** Подставим в (**) `x = 0`. Имеем `N(0) = G(0) − 0·G′(0) = 1`, `G(−0/α) = G(0) = 1`, `v(−0/α) = v(0) = φ(v)`, `v(G(0)) = v(1) = β`. Тогда:

```
DT(G)v(0) = −α·[ v(1) + G′(1)·φ(v) ]  +  α·v(1)·1
          = −α·G′(1)·φ(v).      (слагаемые с v(1) = β сокращаются: −α·β + α·β = 0)
```

Поскольку `DT(G)v(0) = φ(DT(G) v)`, сравнение с `φ(DT(G)v) = c·φ(v)` даёт

```
c = −α·G′(1) = G′(1)/λ = G′(1)/G(1)   (RAW; = 2G′_X(1)/G(1) в X-записи).
```

Двойка `2` в `X`-записи — это в точности цепное правило §2 (`G′(1) = 2G′_X(1)`). Итак, `φ ∘ DT(G) = c·φ` для **любого** `v ∈ B`, целиком алгебраически, без численных входов. Значение `c` как **числа** обсуждается в §6.

## 5. Координатная мода: `DT(G) N = c·N`

### 5.1. Откуда берётся семейство решений

Уравнение `G(x) = −α·G(G(x/α))` — нормированный (`G(0) = 1`) случай **ненормированного** уравнения Цвитановича—Фейгенбаума

```
g(x) = −α · g( g(x/α) ).                                                 (CF-un)
```

Если `g_F` — решение, то для **любого** `c₀ ≠ 0` функция `g_{c₀}(x) := c₀ · g_F(x/c₀)` — тоже решение. Проверка — чистая подстановка:

```
−α·g_{c₀}(g_{c₀}(x/α))
   = −α·c₀·g_F( g_{c₀}(x/α)/c₀ )          [определение g_{c₀}]
   = −α·c₀·g_F( g_F( x/(c₀ α) ) )          [g_{c₀}(y)/c₀ = g_F(y/c₀)]
   = −α·c₀·( −g_F(x/c₀)/α )               [(CF-un) при аргументе x/c₀]
   = c₀·g_F(x/c₀) = g_{c₀}(x).            ✓
```

Это стандартная координатная («gauge») свобода `x ↦ c₀·x` уравнения до наложения нормировки `g(0) = 1` (при `c₀ ≠ 1` имеем `g_{c₀}(0) = c₀ ≠ 1`, так что нормировку удовлетворяет лишь `g₁ = G`). Никаких свойств конкретной `G`, кроме того что она решает (CF-un), не используется; внешняя ссылка не нужна.

### 5.2. Почему `N` касателен и почему собственное значение равно `c`

Дифференцируя `g_{c₀}(x) = c₀·g_F(x/c₀)` по параметру `c₀` в точке `c₀ = 1`:

```
N(x) := d/dc₀ [ g_{c₀}(x) ]|_{c₀=1} = G(x) − x·G′(x).                   (N)
```

**Сверка с записью `N = G − 2X·G′_X`.** Это та же функция: `x·G′(x) [по x] = x·(2x·G′_X) = 2X·G′_X(X)`, поэтому `G(x) − x·G′(x) = G(X) − 2X·G′_X(X)` — буквально формула теоремы (двойка `2` снова из `dX/dx = 2x`, §2).

Так как `g_{c₀}` — кривая **неподвижных точек** оператора `S(f)(x) := −α·f(f(x/α))` («фиксированно-α» форма; легко проверить, что `g_{c₀} = S(g_{c₀})` для всех `c₀`), дифференцирование тождества `g_{c₀} = S(g_{c₀})` по `c₀` в `c₀ = 1` даёт

```
N = DS(G) · N ,    т.е. N — собственный вектор DS(G) с собственным значением РОВНО 1.
```

Это тривиальное следствие непрерывной координатной симметрии («маргинальная мода»). Но `S` — оператор с фиксированным `α`, а не самоприменённый `T` (где `a = q(1)` меняется при вариации). Их связывает формула §3: главное слагаемое `(**)` для чётного `v` совпадает с `DS(G)v` (здесь достаточно `λ x = −x/α`). Поскольку `N` чётна (`x·G′(x)` — произведение двух нечётных), подставляем `v = N`:

```
DT(G) N(x) = DS(G)N(x) + α·N(1)·N(x) = N(x) + α·N(1)·N(x) = (1 + α·N(1))·N(x).   (5.1)
```

**Алгебраическое упрощение** `1 + α·N(1) = c`:

```
N(1) = G(1) − 1·G′(1) = λ − G′(1),
α·N(1) = α·λ − α·G′(1) = −1 − α·G′(1),           [α·λ = α·(−1/α) = −1]
1 + α·N(1) = −α·G′(1) = G′(1)/λ = c.             [−α = 1/λ;  c = G′(1)/λ из §4]
```

Итого

```
DT(G) N (x) = c · N(x)   для всех x,                                        (Т-мода)
```

с **тем же** `c = G′(1)/G(1)`, что и в §4 (не новое число). Доказано аналитически: (i) прямая подстановка — `g_{c₀}` решает (CF-un) для всех `c₀` (§5.1); (ii) дифференцирование этого тождества по параметру (§5.2); (iii) формула Фреше-производной `T` из §3. **Ни один шаг не использует численные значения коэффициентов `G`** — верно для любой чётной функции, удовлетворяющей (CF) и (CF-un) с тем же `α`.

Структурный итог: `α²` — собственное значение координатной моды `N`, а тождество для `φ` — его двойственная (левая собственная) форма. «Две теоремы» (про `φ` и про `N`) имеют **одну** общую константу `c`.

## 6. Единственное численное звено: `c = α²`

Конструкция §3–§5 даёт `c = G′(1)/G(1)` (одинаковую для `φ` и `N`) чисто аналитически. Осталось показать, что это **число** равно `α²`. Поскольку `G(1) = −1/α` — точное аналитическое следствие (§1, 159 цифр), равенство `c = α²` равносильно

```
G′(1) = −α.                                                              (★)
```

**Это звено — численное, не аналитическое.** Из функционального уравнения `G(x) = −α·G(G(x/α))` тождество (★) не выводится: дифференцирование уравнения даёт `G′(x) = −G′(G(x/α))·G′(x/α)`, и ни в одной точке оно не замыкается на `G′(1) = −α` (при `x = 0` обе части — нули чётной функции, `0 = 0`, без информации). Таким образом, (★) — специфическое численное свойство конкретной универсальной функции `G`, того же уровня глубины, что само её существование и значение `α`.

**Независимая сверка** (560 бит; те же сертифицированные данные, 100 чебышёвских коэффициентов; преобразование Чебышёв → Тейлор в `w`-базисе выполнено заново, отдельной программой):

```
G′(1) [по x]  = −2.50290787509589282228390287321821578638127137672…
α              = +2.50290787509589282228390287321821578638127137672…
c = G′(1)/G(1)=  6.264547831217037425109907407591569949820210471188…
α²             =  6.264547831217037425109907407591569949820210471188…
|G′(1) + α|/α ≈ 2.5·10⁻¹³²        →  (★) выполнено с точностью ~132 цифр
|c − α²|/α²   ≈ 2.5·10⁻¹³²        →  c = α² с точностью ~132 цифры
```

Совпадение ограничено **132 значащими цифрами** (независимая проверка через прямое дифференцирование ряда Чебышёва по t — `09-CODE/section5_base_certificates/h1_package_lemma_A/check_gprime_at_1.py`, 132 совпадающих знака), что меньше полной точности данных (~159 цифр у `G(1) = −1/α`, которое аналитично). Это подтверждает: (★) — не точное алгебраическое тождество, а численная характеристика данной `G`; точность 132 цифры отвечает точности, до которой усечённое (`M = 99`) приближение воспроизводит истинную `G` (а не округлению: относительная невязка 2.5·10⁻¹³² на порядки больше арифметического шара ~10⁻¹⁶⁸). Независимая сверка `α` с опубликованным высокоточным значением даёт ~130 цифр — тот же масштаб.

**Честный вывод.** Доказать `c = α²` «из чистой алгебры» означало бы, по существу, самостоятельно передоказать существование и характеризацию универсальной `G` и числа `α` — то, что уже сделано строгими computer-assisted методами и принято как вход. Это приложение **не** претендует на такое доказательство. Оно делает другое: сводит утверждение 5 к [полностью аналитическая конструкция] + [ровно одна численная характеристика `G′(1) = −α`, подтверждённая на ~132 цифры]. Численная проверка здесь отделена от вывода и не выдаётся за вывод.

## 7. Статус: что аналитически, что численно

**Атрибуция.** Излагаемый результат — классический факт в явной форме для нашей нормировки: замены `x → x + ε x^n` дают собственные значения `α^{1−n}` оператора удвоения (Feigenbaum 1979; Collet–Eckmann–Lanford 1980; Christiansen–Cvitanović–Rugh 1990; Briggs 1994 — последний явно употребляет термин «gauge»). В настоящей работе рассматривается только частный случай d = 2; общая форма для классов `|x|^d` и межклассовая проверка (d = 4, 6) — отдельная работа [компаньон], Приложение A, следствие 3. Приоритета на само тождество не заявляем.

**Доказано аналитически (без численных входов):**

- Формула производной Фреше `DT(G)v(x)` самоприменённого оператора `T`, для произвольных `v ∈ B` и `x` — §3, формула (**), с явной поправкой `+α·v(1)·N(x)` к главному члену.
- **Недостающая двойка** `c = 2G′_X(1)/G(1)` — выведена явно из `dX/dx = 2x` (`X = x²`) в точке `x = 1`, §2; «наивная» `X`-производная даёт ровно `c/2`.
- `φ ∘ DT(G) = c·φ` для любого `v`, `c = G′(1)/G(1)` — §4 (Лемма E₀).
- `DT(G)N = c·N` для всех `x` — §5 (координатное семейство `g_{c₀}`, дифференцирование по параметру, формула §3).
- Совпадение констант `c` в §4 и §5 — §5.2, чистая алгебра.
- `G(1) = −1/α` — точное следствие нормировки и уравнения, §1 (159 цифр).

**Остаётся численным (не выведено аналитически):**

- `G′(1) = −α`, равносильное `c = α²`, — §6. Подтверждено на ~132 значащие цифры (независимый пересчёт по сертифицированным данным; отдельно — конечно-разностная перепроверка формул §3–§5 на 74–84 цифры). Это единственное численное звено всей конструкции.

**Принятые входы** (не передоказываются ни здесь, ни в основном тексте): существование, аналитичность и нормировка универсальной `G` и константы `α` (строгие computer-assisted доказательства, Ланфорд 1982, Кампанино—Эпстейн 1981); сходимость и корректность композиции рядов для `T` в круге `|w| ≤ 1`.

**Атрибуция.** Формулировка утверждения 5 в основном тексте оставляет приоритет и точную ссылку открытыми: тождество укоренено в классической структуре уравнения ренормализации, и мы не заявляем его как новый независимый факт. Координатная свобода `x ↦ c₀ x` (§5.1) доказана здесь прямой подстановкой и внешней атрибуции не требует. Новизна настоящего приложения — в явном выводе, а не в самом тождестве.
