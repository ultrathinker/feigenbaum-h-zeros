# Нули универсальной масштабирующей функции каскада удвоения периода

**Yevhen Borzenkov** · ORCID [0009-0002-7946-589X](https://orcid.org/0009-0002-7946-589X)
Препринт, версия 2.5 (заморожена 16.08.2026), не рецензирован. Публичное издание 15.11.2026.
English version — [README.md](README.md).

Строгая компьютерная локализация нулей универсальной функции H(u) каскада удвоения периода Фейгенбаума
(квадратичный класс, d = 2), голоморфность предела H = lim H_m и численная связь нулей H со сверхустойчивыми
параметрами z² + c вблизи точки Фейгенбаума.

## Главные результаты

Строго (компьютерное доказательство, интервальная арифметика 512 бит с направленным округлением, python-flint / Arb):

- ровно два нуля H в круге |u| < 7, оба вещественные и простые;
- ровно один простой нуль в каждом из 23 сертификатных кругов кольца 7 < |u| < 10
  (46 нулей с сопряжёнными, 48 локализованных нулей в |u| < 10; полнота списка в кольце **не** утверждается);
- голоморфность предельной функции H в |u| < 7 и вблизи каждого используемого замкнутого круга;
- существование и единственность всех 23 сверхустойчивых параметров точного периода 2048 семейства z² + c
  в боксах радиуса 10⁻²⁷ (оператор Кравчика, интервальный Ньютон);
- сертифицированная разметка 23 кругов на шесть полос и закон дрейфа на пяти переходах конечных уровней.

Численно, **не** строго: в одном замороженном прогоне (все параметры зафиксированы заранее) нули H совпали
с δ-масштабированными сверхустойчивыми параметрами в 22 случаях из 23, контроли 0 из 20.

Объект и качественная картина восходят к Милнору (1989); вклад работы — строгий вычислительный слой. Предшественники и атрибуция — §1 и приложение G.

## Как воспроизвести

Python 3.13, `python-flint` 0.9.0, `mpmath` ≥ 1.3. Порядок — в [`ru/README-CODE.md`](ru/README-CODE.md), §4–§6.
Быстрые проверки: `python 09-CODE/_tools/verify_manifest.py` и `python 09-CODE/_tools/check_article_paths.py`.
Ожидаемо одно задокументированное расхождение пина sha256 на `x4_common.py` — см. `PUBLICATION-NOTES.md`,
на математику оно не влияет.
